# PWA / Windows 验收记录模板

记录作品、版本、提交、构建工具与实际测试机器；每项填写 PASS/FAIL/未执行及证据路径。

| 范围 | 检查与证据 |
| --- | --- |
| 原生内容 | 全路线、稳定场景/台词 ID、结局、无效存档拒绝、旧存档恢复 |
| 阅读 | 全窗口、透明度、隐藏暂停/恢复、选择、历史/回看、退出与重新打开 |
| PWA | HTTPS/子路径、独立 scope/cache、清空后首次加载、安装、全资源缓存成功、断网重开、缺失资源失败后可恢复 |
| Windows | 实际发行 EXE 启动/读档/设置/退出，记录截图与退出码；源码 smoke 与跨平台打包单列 |
| 布局 | 1440×900、412×915、568×320、844×390；旋转保留阅读位置 |
| 素材 | 校验/导出、许可、源图/请求/哈希、透明边界、所有 JSON 字形 |
| 性能 | 同机器、相同缓存/视口至少三次；启动、首次可读/交互、体积的中位数与最差值 |
| 公开发布 | 精确提交的 CI、Pages 地址、真实线上主要路径、控制台/网络、安装包链接 |

Ren'Py 和 React 使用各自原生存档与剧情执行器。图结构通过不能替代可玩路线；CI 成功不能替代实际 Windows 包与公开页面的运行证据。
