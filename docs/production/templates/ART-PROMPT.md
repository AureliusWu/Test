# 图像请求模板

作品：{独立作品名}；角色身份、年龄和关系：{以本作品角色设定为准}。
画风依据：{授权来源与具体参考图}；输出：{背景/透明立绘/表情图集/CG}。
尺寸：{宽×高}；构图：{全窗口主体与底部阅读层留白}；alpha：{需要时要求透明背景}。
本次变化：{只描述此资产的变化}；保持项：{人物身份、服装、比例、连续剧情事实}。
不要在图中绘制 UI、文字、标识或水印。图集记录行列、表情顺序、每格完整人物边界；加工脚本只编码与裁切，不生成未批准的表情或内容。

生成后保存：实际发送请求、参考文件哈希、生成器版本/日期、原图、许可、源图 SHA-256、运行格式 SHA-256、尺寸和 alpha 校验。负责人审批状态与技术校验状态分别记录。
