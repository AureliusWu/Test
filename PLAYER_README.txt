雨停之前 / Before the Rain Stops
版本：1.2.0

雨夜的旧车站，两位久未联系的旧友，和一封没有寄出的信。
中文短篇视觉小说，六章、四次关键选择、Normal / True 两个结局。
包含七种角色表情、四个背景、旧信 CG 与 17 句 Qwen 中文关键语音。

运行
完整解压整个文件夹到可写目录，再双击 BeforeTheRainStops.exe。
请保留 game、lib、renpy 等随包目录。不要直接从压缩包内启动。
游戏可以离线运行，无需安装 Python、Ren'Py 或配音模型。

浏览器 / PWA
网页版：https://aureliuswu.github.io/Rain/ 。首次联网下载完整内容后，右上角会显示“完整内容已保存，可离线重开”。
支持安装的浏览器可点“安装到设备”；其他浏览器使用菜单中的安装 / 添加到主屏幕。
浏览器左上角菜单可导入 / 导出 Ren'Py 原生存档。浏览器数据被清理时可能丢失本机存档，请导出备份。
新版准备完成后，请关闭此应用的所有窗口再重开；正在阅读的旧窗口继续使用原版本。

操作
鼠标左键、空格或 Enter：推进对白；右键或 Esc：打开 / 返回菜单。
下方按钮：回退、历史、快进、自动播放、存档、读档、快存、快读、设置。
有配音的当前台词可点“重听语音”；历史记录中可点“重播语音”重听已读录音。
设置可分别调整音乐、音效、语音音量，以及文字速度和自动播放间隔。
F：全屏 / 窗口；H：隐藏界面；滚轮向上：回退已读台词。
快进会在选择处停止。结局页可返回主菜单，重新开始另一条路线。

显示与存档
游戏原生画布为 1920×1080；默认 1280×720 窗口，可拖动边缘调整。
全屏与窗口由引擎按显示器比例缩放。建议首次运行使用默认设置。
本版本使用独立 v1 存档目录：AureliusWu-BeforeTheRainStops-v1。
Windows 存档位于 %APPDATA%\RenPy\AureliusWu-BeforeTheRainStops-v1。
v1.0.0 存档继续使用同一目录；更早阶段存档保留，不跨阶段加载。
